# Flipkart Gridlock

This repository contains the work and submissions for the Flipkart Grid hackathon/competition.

## Project Structure

- `dataset/`: Contains the provided datasets.
  - `train.csv`
  - `test.csv`
  - `sample_submission.csv`
- `src/`: Source code directory.
  - `pipeline.py`: Main processing pipeline and modeling script.
- `outputs/`: Stores the prediction outputs generated by the pipeline.
  - `submission_v1.csv`
  - `submission_v2.csv`
  - `submission_v3.csv`

## Environment Setup

A local Python virtual environment (`.venv`) has been configured for dependency management.

## Progress Till Now

- **Repository Setup**: Initialized Git repository and connected to remote (`https://github.com/naksshhh/Flipkart_Gridlock.git`). Set up `.gitignore` for standard exclusions.
- **Data Organization**: Placed the train, test, and sample submission files into the `dataset/` folder.
- **Pipeline Development**: Created the initial inference/training pipeline in `src/pipeline.py`.
- **Submissions**: Generated three iterations of submissions (`v1`, `v2`, `v3`) in the `outputs/` folder, indicating ongoing modeling experiments and improvements.
